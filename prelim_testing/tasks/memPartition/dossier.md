## Object

`VTask.memPartition f n` is a finite collection (a set of sets) of subsets of a type `α`, constructed from a sequence of sets `f : ℕ → Set α` by a recursive process indexed by a natural number `n`. At level `n`, the collection partitions the entire universe `univ` into at most `2^(n+1)` pieces, where each piece is characterized by a consistent membership pattern with respect to `f 0, f 1, …, f (n−1)`: every point in a given piece either belongs to `f i` or to its complement, for each `i < n`, and all points sharing the same pattern are grouped into the same piece. Concretely, level 0 contains only the single set `univ`, and each subsequent level refines the previous partition by splitting every piece into two parts — one intersected with the new set `f n` and one from which `f n` is removed (the set-difference).

`VTask.memPartition : {α : Type u_1} -> (f : ℕ → Set α) -> ℕ → Set (Set α)`

The implicit type argument `α` is the ambient type whose subsets are being partitioned. The argument `f` is a countable sequence of sets whose successive members drive the refinement of the partition at each level. The natural number argument `n` is the depth of refinement: how many sets from the sequence `f` have been used to split the partition.

## Conventions

The partition at level 0 is always the singleton collection `{univ}`, regardless of `f`. Empty sets can appear as members of the partition at positive levels (for example, if `f n = univ`, the difference piece at level `n+1` will be empty); no non-emptiness constraint is enforced on the pieces.

## Worked examples

- Claim: At level 0, `VTask.memPartition f 0` equals `{Set.univ}` for any `f`.

- Claim: At level 1, `VTask.memPartition f 1` contains exactly two sets: `Set.univ ∩ f 0` and `Set.univ \ f 0`.

- Claim: For any `f` and `n`, the union of all sets in `VTask.memPartition f n` is `Set.univ`.

- Claim: `VTask.memPartition f n` is always a finite collection.

- Claim: If `s ∈ VTask.memPartition f n`, then `s` can be written as a finite intersection of sets of the form `f i` or `(f i)ᶜ` for `i < n`.

## Boundaries

- At `n = 0` the sequence `f` plays no role: the unique element of the partition is `Set.univ`.
- Pieces can be empty: if `f k = ∅` for some `k`, then at level `k+1` the piece `u ∩ f k = ∅` for every `u` from the previous level, so the partition contains empty sets.
- The number of pieces is at most `2^(n+1)` but can be strictly less if some splits produce duplicates or empty sets.
- The partition always covers `univ`: the union of all sets in `VTask.memPartition f n` equals `Set.univ`.
- The partition is coarser at lower levels and refines monotonically as `n` grows: the σ-algebra generated by level `n` is contained in that generated by level `n+1`.

## Not to be confused with

- `memPartitionSet f n a`: the single piece of the level-`n` partition that contains the specific point `a`, rather than the whole collection of pieces.
- An arbitrary partition or measurable partition: `VTask.memPartition f n` is a specific constructive partition built from the sequence `f` by binary splitting, not a general abstract partition.
- The range `Set.range f`: the collection `{f n | n : ℕ}` of the sets themselves, as opposed to the intersection-and-complement atoms built from them.

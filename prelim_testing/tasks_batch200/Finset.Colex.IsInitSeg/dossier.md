## VTask.IsInitSeg

### Object

A predicate asserting that a finite collection `𝒜` of finite sets is an *initial segment* of the colexicographic (colex) order restricted to sets of a fixed size `r`. Concretely, this means two things simultaneously: every set in `𝒜` has exactly `r` elements, and `𝒜` is downward-closed in colex among all `r`-element sets — that is, if `s` belongs to `𝒜` and `t` is any `r`-element set that comes strictly before `s` in colex order, then `t` also belongs to `𝒜`.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.IsInitSeg : {α : Type u_1} -> [LinearOrder α] -> (𝒜 : Finset (Finset α)) -> (r : ℕ) -> Prop
<!-- PINNED-SIGNATURE:END -->


The implicit type parameter `α` is the element type, which must carry a linear order (used to define the colexicographic order on finite sets). The argument `𝒜` is the finite family of finite sets whose membership in the initial-segment class is being tested. The argument `r` is the uniform size that every member of `𝒜` must have, and is the rank at which the colex order is interrogated.

### Conventions

The empty family `𝒜 = ∅` trivially satisfies `VTask.IsInitSeg ∅ r` for every `r`, because both the sizing condition (vacuously, every element has size `r`) and the downward-closure condition (vacuously, there is no `s ∈ ∅` to start from) hold. No junk-value convention is needed for the natural-number argument `r`: the predicate is well-defined for all `r`, including `r = 0`, in which case the only `r`-element set is the empty set `∅`, so `𝒜` is an initial segment of rank 0 iff `𝒜 = ∅` or `𝒜 = {∅}`.

### Worked examples

- Claim: For any linearly ordered type `α`, `VTask.IsInitSeg (∅ : Finset (Finset α)) r` holds for all `r`, since both conditions are vacuously satisfied by the empty family.

- Claim: If `s : Finset α` has size `r`, then the principal initial segment `initSeg s` (the family of all `r`-element colex-predecessors of `s`, together with `s` itself) satisfies `VTask.IsInitSeg (initSeg s) r`. This is witnessed by the theorem `isInitSeg_initSeg`.

- Claim: Any two families `𝒜₁` and `𝒜₂` both satisfying `VTask.IsInitSeg _ r` are totally ordered by inclusion: either `𝒜₁ ⊆ 𝒜₂` or `𝒜₂ ⊆ 𝒜₁`. This is the totality theorem `IsInitSeg.total`.

- Claim: If `𝒜` satisfies `VTask.IsInitSeg 𝒜 r` and `α` is a finite type, then the shadow `∂ 𝒜` (obtained by removing one element from each set in `𝒜` in all possible ways) satisfies `VTask.IsInitSeg (∂ 𝒜) (r - 1)`.

### Boundaries

- **Empty family**: `VTask.IsInitSeg ∅ r` holds for every `r`; the empty family is an initial segment of every rank.
- **Rank 0**: The only set of size 0 is `∅`. So `VTask.IsInitSeg 𝒜 0` holds iff `𝒜 = ∅` or `𝒜 = {∅}` (since there is nothing colex-smaller than `∅` of size 0, the only valid initial segments are the empty family and the singleton containing the empty set).
- **Full family**: The family of *all* `r`-element subsets of a finite type is itself an initial segment of rank `r`, since it is trivially downward-closed.
- **Non-uniform families**: If `𝒜` contains sets of different sizes, `VTask.IsInitSeg 𝒜 r` fails immediately because the sizing condition requires every element to have exactly `r` elements.
- **Characterization**: When `𝒜` is nonempty, `VTask.IsInitSeg 𝒜 r` holds if and only if `𝒜` equals `initSeg s` for some `r`-element set `s`, i.e., every nonempty initial segment is a principal one.

### Not to be confused with

- **`initSeg s`**: This is the *specific* initial segment generated by a single set `s` (all colex-predecessors of `s` of the same size, plus `s`); `VTask.IsInitSeg` is the *predicate* characterizing families with this shape.
- **Downward-closure in full colex order (across all sizes)**: `VTask.IsInitSeg` only enforces downward-closure among sets of the *same* fixed size `r`; it does not require closure under taking subsets or under colex comparisons between sets of different sizes.
- **`Finset.Colex.toColex`**: This is the type-level wrapper converting a `Finset` into its colex-ordered version; it is a constituent tool used in the definition of `VTask.IsInitSeg` but is not itself a predicate on families.

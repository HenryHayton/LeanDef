## VTask.Join

### Object

`VTask.Join r` is the *join* (also called the *Church–Rosser relation* or *confluent closure step*) of a binary relation `r` on a single type `α`. Two elements `a` and `b` are related by `VTask.Join r` if and only if there exists a third element `c` such that both `a` and `b` are related to `c` by `r`. Informally, `a` and `b` can be "joined" in the sense that they share a common successor under `r`.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.Join : {α : Type u_1} -> (r : α → α → Prop) -> α → α → Prop
<!-- PINNED-SIGNATURE:END -->


`{α : Type u_1} -> (r : α → α → Prop) -> α → α → Prop`

The implicit argument `α` is the carrier type on which the relation lives. The explicit argument `r` is the base binary relation whose join is being formed. The final two arguments are the pair of elements being tested for membership in the join relation.

### Conventions

There are no special junk-value or boundary conventions for this definition: `VTask.Join r` is defined for all types `α` and all binary relations `r` on `α` without restriction. The definition is uniformly meaningful across all inputs.

### Worked examples

- Claim: For the equality relation on `ℕ`, `VTask.Join Eq 3 3` holds (take the witness `c = 3`).

- Claim: For the relation `r` on `{1, 2, 3}` where `r 1 3` and `r 2 3`, `VTask.Join r 1 2` holds because both `1` and `2` are related to `3`.

- Claim: If `r a c` and `r b c` hold for some `c`, then `VTask.Join r a b` holds — the witness is `c` itself.

- Claim: `VTask.Join r` is symmetric: if `VTask.Join r a b` then `VTask.Join r b a`, since the same witness `c` satisfying `r a c ∧ r b c` also satisfies `r b c ∧ r a c`.

- Claim: If `r` is reflexive, then `r ≤ VTask.Join r`, meaning every pair `(a, b)` related by `r` is also related by `VTask.Join r` (using `b` as the witness, via `r a b` and `r b b`).

### Boundaries

- **Empty relation**: If `r` is the empty relation (no pair is related), then `VTask.Join r` is also empty, since no witness `c` can exist.
- **Universal relation**: If `r` relates every pair, then `VTask.Join r` also relates every pair, since any `c` serves as a witness.
- **Reflexive relations**: When `r` is reflexive, `VTask.Join r` contains `r` as a sub-relation (every `r`-related pair has a common successor).
- **Diagonal / equality**: `VTask.Join Eq a b` holds if and only if `a = b`, because the only witnesses are `a` itself (forcing `b = a`) or `b` itself (forcing `a = b`).
- **Non-symmetric `r`**: Even though `r` need not be symmetric, `VTask.Join r` is always symmetric by construction.

### Not to be confused with

- `Relation.ReflTransGen r`: the reflexive-transitive closure of `r`; it chains forward steps rather than finding a common target.
- `Relation.EqvGen r`: the equivalence relation generated by `r`; it is the smallest equivalence relation containing `r`, not merely the one-step join.
- `Relation.Comp r s`: the composition of two relations `r` and `s`, where `a` is related to `b` if there is an intermediate `c` with `r a c` and `s c b` — note the direction of the second relation is forward, not backward as in `VTask.Join`.

## VTask.permsOfList

### Object

`VTask.permsOfList l` takes a list `l` of elements of a type with decidable equality and returns a list of permutations (bijections from the type to itself) that are generated by the elements of `l`. Concretely, it produces all permutations of the type that can be expressed as products of transpositions swapping the elements appearing in `l` against each other, starting from the identity. When `l` enumerates all elements of a finite type, the result is a complete list of all permutations of that type.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.permsOfList : {α : Type u_1} -> [DecidableEq α] -> List α → List (Equiv.Perm α)
<!-- PINNED-SIGNATURE:END -->


The implicit type argument `α` is the base type whose elements are being permuted; it must admit decidable equality so that element comparisons (needed for building transpositions) can be performed. The single explicit argument is the list of elements that seeds the permutation-generating process: successive elements of the list are used to extend the permutations accumulated so far via transpositions.

### Conventions

For the empty list, the function returns the singleton list containing only the identity permutation `[1]`; this is the base case and not a degenerate or error value.

### Worked examples

- Claim: `VTask.permsOfList ([] : List Empty)` equals `[1]` — the empty list yields only the identity permutation.
  ```lean
  example : VTask.permsOfList ([] : List Empty) = [1] := by decide
  ```

- Claim: `VTask.permsOfList [0, 1, 2]` (as a list over a type such as `Fin 3`) has length 6, matching `3! = 6`.

- Claim: The identity permutation is always a member of `VTask.permsOfList l` for any list `l`.

- Claim: For `l = [a, b]` with `a ≠ b`, `VTask.permsOfList l` contains both the identity and the transposition swapping `a` and `b`.

### Boundaries

- **Empty list**: Returns `[1]` (a list containing exactly the identity permutation). This is well-defined and intentional, not a degenerate case.
- **Singleton list `[a]`**: Returns `[1]` — there is only one permutation expressible from a single element (the identity), since the only possible transposition is `swap a a = 1`.
- **Repeated elements**: If the list contains duplicate elements, the output list may contain duplicate permutations; no deduplication is performed.
- **Type with one element**: For a type with a single element (e.g., `Unit`), every permutation is the identity, so the output is a list of copies of `1`.

### Not to be confused with

- `List.permutations`: Produces rearrangements of the list itself (lists of the same elements in different orders), not `Equiv.Perm` values.
- `Equiv.Perm.equivFin`: Establishes a bijection between `Perm (Fin n)` and `Fin n!`, a structural equivalence rather than an explicit enumeration.
- `Finset.univ` on `Equiv.Perm α`: The canonical finite set of all permutations as a `Finset`, not an ordered `List` produced by this recursive construction.

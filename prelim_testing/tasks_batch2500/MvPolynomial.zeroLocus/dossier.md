## Object

The **zero locus** of an ideal $I \subseteq k[x_1, x_2, \ldots]$ (a multivariate polynomial ring over a field $k$, with variable set $\sigma$) relative to an extension field $K \supseteq k$ is the set of all $K$-points — that is, all functions $\sigma \to K$ — at which every polynomial in $I$ vanishes simultaneously. Concretely, a point $x : \sigma \to K$ belongs to this set if and only if evaluating every polynomial $p \in I$ at $x$ (by substituting $x(i)$ for each variable $i$) yields $0$ in $K$. This is the algebro-geometric notion of the variety cut out by $I$, considered over the extension field $K$.

VTask.zeroLocus : {k : Type u_1} -> (K : Type u_2) -> [Field k] -> [Field K] -> [Algebra k K] -> {σ : Type u_3} -> (I : Ideal (MvPolynomial σ k)) -> Set (σ → K)

The implicit argument `k` is the base field whose polynomial ring is used. The explicit argument `K` is the extension field in which the zeroes are sought (it must itself be a field extending `k` via the `Algebra k K` instance). The implicit argument `σ` is the type indexing the variables of the polynomial ring. The argument `I` is the ideal of multivariate polynomials over `k` whose simultaneous zero set we are computing. The result is a subset of the function space `σ → K`, i.e., the set of all assignments of elements of $K$ to the variables that make every polynomial in $I$ equal to zero.

## Conventions

No special junk-value or boundary conventions are declared for this definition: it is a mathematically total construction that yields a well-defined set for any ideal $I$, including the zero ideal and the unit ideal, without any degenerate cases requiring special treatment.

## Worked examples

- Claim: For the zero ideal in `k[X]` (one variable), every point of `K` is in the zero locus, since the only polynomial to satisfy is `0`, which vanishes everywhere.

- Claim: For the unit ideal `⊤` in `MvPolynomial σ k`, the zero locus `VTask.zeroLocus K ⊤` is the empty set `∅`, because the constant polynomial `1 ∈ ⊤` does not vanish at any point.

- Claim: For the ideal generated by `X - c` (a single linear polynomial, one variable, `c` a constant), the zero locus over `K` consists of exactly the single point `fun _ => c` (where `c` is viewed in `K` via the algebra map), reflecting that this polynomial has exactly one root.

- Claim: If `I ≤ J` as ideals (i.e., `I ⊆ J`), then `VTask.zeroLocus K J ⊆ VTask.zeroLocus K I`, reflecting that a larger ideal imposes more vanishing conditions and thus cuts out a smaller (or equal) locus.

## Boundaries

- **Zero ideal (`I = ⊥`):** The zero ideal contains only the zero polynomial. Since the zero polynomial vanishes everywhere, the zero locus is all of `σ → K` — the full ambient space.
- **Unit ideal (`I = ⊤`):** The unit ideal contains the constant polynomial `1`, which never vanishes. Thus the zero locus is the empty set `∅`.
- **Empty variable set (`σ = Empty` or `σ = Fin 0`):** The function space `σ → K` has exactly one element (the empty function). The zero locus is either `{∅}` (if all polynomials in `I` are zero) or `∅` (if some nonzero constant lies in `I`).
- **Radical and non-radical ideals:** The definition treats `I` and its radical identically from the point of view of the zero locus over algebraically closed fields (Nullstellensatz), but the definition itself does not assume algebraic closure of `K`; over non-algebraically-closed fields the zero locus may be smaller or even empty for non-unit ideals with no $K$-rational roots.

## Not to be confused with

- **`AlgebraicGeometry.zeroLocus` or `PrimeSpectrum.zeroLocus`:** These define the zero locus as a set of *prime ideals* (i.e., a closed set in the Zariski topology on Spec), not as a set of field-valued points.
- **`MvPolynomial.roots`:** Refers to roots of a single polynomial rather than the common vanishing locus of an entire ideal.
- **The vanishing ideal functor (the map going the other direction):** Given a set of points $S \subseteq K^\sigma$, one can form the ideal of all polynomials vanishing on $S$; this is the adjoint/inverse construction to the zero locus, not the same object.

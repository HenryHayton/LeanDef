## VTask.powers

### Object

Given a monoid `M` and an element `n : M`, `VTask.powers n` is the submonoid of `M` consisting of all non-negative integer powers of `n`, that is, the set `{n^0, n^1, n^2, …} = {1, n, n², n³, …}`. It is the smallest submonoid of `M` that contains `n`.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.powers : {M : Type u_1} -> [Monoid M] -> (n : M) -> Submonoid M
<!-- PINNED-SIGNATURE:END -->


`{M : Type u_1} -> [Monoid M] -> (n : M) -> Submonoid M`

The implicit type argument `M` is the ambient monoid. The instance argument supplies the monoid structure (unit and associative multiplication). The explicit argument `n` is the generating element whose powers populate the submonoid.

### Conventions

The indexing of powers uses the natural numbers `ℕ`, so the exponents are 0, 1, 2, … in particular the identity element `1 = n^0` is always a member, consistent with the requirement that any submonoid contains the identity.

### Worked examples

- Claim: In the multiplicative monoid of natural numbers, `4` belongs to `VTask.powers 2` because `4 = 2^2`.

- Claim: The identity element `1` belongs to `VTask.powers n` for any `n : M`, because `1 = n^0`.

- Claim: For `n : ℕ` (multiplicative monoid), `3` does **not** belong to `VTask.powers 2`, since no natural-number power of 2 equals 3.

- Claim: `VTask.powers 1 = ⊥` in any monoid where `⊥` is the trivial submonoid `{1}`, because every power of `1` is `1`.

### Boundaries

- When `n = 1` (the identity), every power `1^k = 1`, so `VTask.powers 1` is the trivial submonoid `{1}`.
- When the monoid is a group and `n` has finite order `d`, the set of powers cycles through `{n^0, n^1, …, n^(d-1)}` and is finite; otherwise it may be infinite.
- The exponent `0` is always included, so `1 ∈ VTask.powers n` unconditionally.
- The construction is valid for any `Monoid`, including additive-written monoids (where "powers" become multiples under the additive analogue).

### Not to be confused with

- `Submonoid.closure {n}`: the closure of the singleton `{n}`; this coincides with `VTask.powers n` but is defined via a different universal construction (arbitrary intersections of submonoids containing `n`).
- `zpowers n` (the subgroup generated by `n` in a group): this also includes negative-exponent powers `n^(-k)` and lives in a `Group`, not merely a `Monoid`.
- `Submonoid.mrange f` (the image of a monoid homomorphism): `VTask.powers n` is internally built using this, but conceptually it is just the set of powers of a single element, not the image of an arbitrary homomorphism.

## Object

The **equalizer** of two R-algebra homomorphisms ϕ, ψ : A →ₐ[R] B is the largest R-subalgebra of A on which ϕ and ψ agree. Concretely, its underlying set is {a ∈ A | ϕ(a) = ψ(a)}, and this set is closed under addition, multiplication, and the unit, making it a subalgebra.

`VTask.equalizer : {R : Type u_1} -> {A : Type u_2} -> {B : Type u_3} -> [CommSemiring R] -> [Semiring A] -> [Algebra R A] -> [Semiring B] -> [Algebra R B] -> (ϕ ψ : A →ₐ[R] B) -> Subalgebra R A`

The scalar ring `R` is a commutative semiring that acts uniformly on both `A` and `B` via their respective `Algebra R` instances. The types `A` and `B` are semirings equipped with R-algebra structures. The first explicit argument `ϕ` is one of the two R-algebra homomorphisms from A to B; the second explicit argument `ψ` is the other. The result is the R-subalgebra of A consisting of all elements on which ϕ and ψ coincide.

## Conventions

The algebra map from R into A always lands inside the equalizer, because every R-algebra homomorphism commutes with the algebra map; this is a definitional member, not an extra hypothesis.

## Worked examples

- Claim: For the identity homomorphism `id` and any other homomorphism `ψ : A →ₐ[R] A`, the equalizer `VTask.equalizer id ψ` contains exactly the elements fixed by `ψ`.

- Claim: For two equal homomorphisms ϕ = ψ, every element of A belongs to `VTask.equalizer ϕ ψ`, so the equalizer is the full algebra `⊤`.

- Claim: For a scalar `r : R`, the element `algebraMap R A r` belongs to `VTask.equalizer ϕ ψ` for any ϕ and ψ, since both homomorphisms must send it to `algebraMap R B r`.

- Claim: An R-subalgebra S ≤ A satisfies S ≤ VTask.equalizer ϕ ψ if and only if ϕ and ψ agree on every element of S (i.e., Set.EqOn ϕ ψ ↑S).

## Boundaries

- When ϕ = ψ identically, the equalizer is all of A (the top subalgebra).
- When ϕ and ψ disagree on every non-scalar element, the equalizer is the image of the algebra map (the minimal subalgebra generated by scalars), because scalars are always in the equalizer.
- The equalizer is always nonempty: it contains 0, 1, and all scalar multiples of 1.
- If A = B and ϕ = id, then the equalizer is the set of fixed points of ψ, which is a legitimate subalgebra.
- The construction is symmetric in name but not in type: ϕ and ψ must both go from A to B; swapping their order gives the same underlying set (since equality is symmetric), hence `VTask.equalizer ϕ ψ = VTask.equalizer ψ ϕ`.

## Not to be confused with

- `NonUnitalAlgHom.equalizer`: the analogous construction for non-unital algebra homomorphisms, which yields a non-unital subalgebra.
- `StarAlgHom.equalizer`: the equalizer for star-algebra homomorphisms, living in the category of star-algebras.
- `LinearMap.eqLocus`: the equal locus of two R-linear maps, which is merely an R-submodule; the present construction adds the multiplicative structure to make it a full subalgebra.

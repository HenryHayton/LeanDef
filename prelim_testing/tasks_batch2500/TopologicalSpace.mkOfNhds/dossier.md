## VTask.mkOfNhds

### Object

Given an assignment `n` of a filter to each point of a type `α`, `VTask.mkOfNhds n` is the topological space on `α` whose open sets are exactly those sets `s` such that, for every point `a` in `s`, the set `s` is a member of the filter `n a`. In other words, a set is declared open when it is a neighborhood (in the sense of `n`) of each of its own points. This mirrors the classical characterisation of open sets via neighborhood systems: a set is open iff every one of its points has it as a neighborhood.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.mkOfNhds : {α : Type u} -> (n : α → Filter α) -> TopologicalSpace α
<!-- PINNED-SIGNATURE:END -->


The sole argument `n` is a function assigning to each point `a : α` a filter on `α`, intended to play the role of the neighborhood filter at `a`. The resulting `TopologicalSpace α` is built entirely from this assignment.

### Conventions

No special junk-value or edge conventions are declared for this definition: the construction is total and well-defined for any function `n : α → Filter α`, even if the filters fail to satisfy the standard neighborhood-system axioms (principality, convergence, etc.). When the axioms are not satisfied, the resulting topology may not have `n a` as the actual neighborhood filter at `a` in the induced topology.

### Worked examples

- Claim: When `n` is the principal-filter assignment `n a = 𝓟 {a}` (the discrete neighborhood filter), `VTask.mkOfNhds n` is the discrete topology, because every singleton `{a}` is open: for any `a ∈ s`, `s` is a superset of `{a}`, and supersets of `{a}` belong to `𝓟 {a}`.

- Claim: When `n a = ⊤` for all `a` (the coarsest filter, containing every set), every set is open in `VTask.mkOfNhds n`, so the resulting topology is the discrete topology (the finest topology).

- Claim: When `n a = ⊥` for all `a` (the indiscrete filter, containing only `∅`), no non-empty set `s` can satisfy `s ∈ n a` for all `a ∈ s`, so only `∅` and `univ` are open, giving the indiscrete topology.

- Claim: For the standard topology on `ℝ` (generated by open intervals), `VTask.mkOfNhds (nhds · )` coincides with the standard topology on `ℝ`, since the standard topology is characterised precisely by the property that open sets are neighborhoods of all their points.

### Boundaries

- If `n` does not satisfy the neighborhood-filter axioms (e.g., `n a` does not contain the principal filter `𝓟 {a}`, meaning `{a} ∉ n a`), the construction still produces a valid `TopologicalSpace`, but the actual neighborhood filter of `a` in the resulting topology may differ from `n a`.
- The empty set is always open: the condition `∀ a ∈ ∅, …` is vacuously true for any `n`.
- The whole set `univ` is always open: for any filter `n a`, `univ ∈ n a` since every filter contains the whole space.
- Arbitrary unions and finite intersections of open sets (in the sense of `n`) remain open by the filter properties of membership.

### Not to be confused with

- `TopologicalSpace.nhds`: Given an *existing* `TopologicalSpace`, `nhds a` is the actual neighborhood filter at `a`; `VTask.mkOfNhds` goes the other direction, *constructing* a topology from a filter assignment.
- `TopologicalSpace.mkOfClosure` or similar closure-operator constructions: those build a topology from a closure operator rather than from a neighborhood filter assignment.
- `Filter.generate`: constructs a filter from a set of sets, not a topology from filters.

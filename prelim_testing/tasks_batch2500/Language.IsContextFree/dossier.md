## Object

A language `L` over an alphabet `T` is **context-free** if there exists a context-free grammar (CFG) whose generated language equals `L` exactly. A context-free grammar is a finite set of production rules of the form `A → w`, where `A` is a single non-terminal symbol and `w` is a (possibly empty) string of terminals and non-terminals; the language of the grammar is the set of all terminal strings derivable from a designated start symbol.

`VTask.IsContextFree : {T : Type u_1} -> (L : Language T) -> Prop`

The implicit type argument `T` is the alphabet (the type of terminal symbols). The explicit argument `L` is the formal language over `T` — a set of finite strings over `T` — whose context-freeness is being asserted.

## Conventions

No special junk-value or boundary conventions are declared for this definition: it is a purely existential proposition and is well-formed for every language `L`, including the empty language and the language containing only the empty string.

## Worked examples

- Claim: The language `{aⁿbⁿ | n ≥ 0}` over `{a, b}` is context-free, witnessed by the grammar `S → ε | a S b`.

- Claim: Every regular language is context-free (regular grammars are a special case of context-free grammars, so any language accepted by a finite automaton has a CFG generating it, hence `VTask.IsContextFree` holds for it).

- Claim: The language `{aⁿbⁿcⁿ | n ≥ 0}` over `{a, b, c}` is **not** context-free; the pumping lemma for context-free languages rules it out, so `¬ VTask.IsContextFree {w | ∃ n, w = replicate n a ++ replicate n b ++ replicate n c}` holds.

- Claim: The empty language `∅` is context-free, witnessed by a grammar whose start symbol has no productions.

## Boundaries

- The empty language (containing no strings) is context-free: a grammar with a start symbol and no reachable terminal productions witnesses this.
- The language containing only the empty string `{ε}` is context-free: the grammar `S → ε` witnesses it.
- The full language `T*` (all strings over `T`) is context-free: the grammar `S → ε | x S` for each terminal `x` witnesses it (for finite alphabets).
- The definition is a `Prop` (not a computable predicate), so there is no algorithm that decides `VTask.IsContextFree L` for an arbitrary `L`; establishing it requires explicitly constructing a CFG or applying a theorem.

## Not to be confused with

- **`Language.IsRegular`**: the analogous predicate asserting the language is generated by a regular grammar (or accepted by a finite automaton); every regular language is context-free, but not vice versa.
- **`ContextFreeGrammar.language`**: the language *of* a specific given grammar, which is always context-free by definition; `VTask.IsContextFree L` instead asserts that *some* grammar exists whose language equals `L`.
- **`Language.IsDeterministicContextFree`** (if present): the stricter class of languages accepted by deterministic pushdown automata, which is a proper subclass of the context-free languages.

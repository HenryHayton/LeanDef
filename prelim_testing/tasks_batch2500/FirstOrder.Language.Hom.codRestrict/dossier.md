## VTask.codRestrict

### Object

Given a first-order language `L`, two `L`-structures `M` and `N`, a substructure `p` of `N`, and a homomorphism `f : M → N` whose entire image is contained in `p`, `VTask.codRestrict p f h` is the homomorphism `M → p` obtained by viewing `f` as mapping into `p` rather than all of `N`. It is the same function as `f` at the level of underlying sets, but with the codomain trimmed to `p`.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.codRestrict : {L : FirstOrder.Language} -> {M : Type w} -> {N : Type u_1} -> [L.Structure M] -> [L.Structure N] -> (p : L.Substructure N) -> (f : L.Hom M N) -> (h : ∀ (c : M), f c ∈ p) -> L.Hom M ↥p
<!-- PINNED-SIGNATURE:END -->


The first argument `p` is the substructure of `N` that serves as the new codomain. The second argument `f` is the original `L`-homomorphism from `M` to `N`. The third argument `h` is a proof that every element of `M` maps under `f` into `p`, i.e., a witness that the image of `f` is contained in `p`.

### Conventions

There are no junk-value or edge-case conventions declared for this definition: it is a total construction that is well-defined for any homomorphism `f` satisfying the containment hypothesis `h`, and there is no input regime that would yield a degenerate or conventional default output.

### Worked examples

- Claim: If `f : M →[L] N` satisfies `∀ c, f c ∈ p`, then for any `m : M`, the underlying `N`-value of `(VTask.codRestrict p f h) m` equals `f m`.

- Claim: When `M = N` and `f` is the identity homomorphism on an `L`-structure `N`, and `p` is a substructure of `N` containing all elements of `N` (i.e., `p = ⊤`), then `VTask.codRestrict p f h` is a homomorphism `N → ⊤` whose underlying map sends each `n` to the canonical element of `⊤` corresponding to `n`.

- Claim: When `p` is the image substructure of some homomorphism `g : M →[L] N`, the codomain restriction of `g` along the proof that `∀ c, g c ∈ image(g)` yields a surjective homomorphism `M → image(g)`.

### Boundaries

- If `p` is the whole substructure `⊤` of `N`, then the codomain-restricted hom `M → ⊤` is essentially isomorphic to the original hom `M → N`, modulo the identification of `⊤` with `N`.
- If `p` is the smallest substructure (e.g., generated by constants), the proof obligation `h` becomes very restrictive, but when satisfied the construction still yields a valid hom.
- The hypothesis `h` is checked pointwise: it must hold for every element of `M`. There is no continuity or topological requirement; the construction is purely algebraic.
- The resulting homomorphism preserves all function symbols and relation symbols of `L`, since these properties are inherited directly from `f`.

### Not to be confused with

- `FirstOrder.Language.Hom.restrict` (domain restriction): that operation restricts the *domain* of a hom to a substructure of `M`, whereas this restricts the *codomain*.
- `FirstOrder.Language.Substructure.inclusion`: that is the canonical hom `p → N` going in the opposite direction, embedding a substructure into the ambient structure.
- `Set.codRestrict` (set-level codomain restriction): that operates on bare functions with no algebraic structure, whereas `VTask.codRestrict` ensures the result is a genuine `L`-homomorphism.

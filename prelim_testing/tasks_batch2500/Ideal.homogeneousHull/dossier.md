## Object

`VTask.homogeneousHull 𝒜 I` is the **homogeneous hull** of an ideal `I` in a graded ring `A`. Concretely, it is the smallest homogeneous ideal of `A` (with respect to the grading `𝒜`) that contains `I`. An ideal is *homogeneous* (with respect to a grading) if it is generated by homogeneous elements, equivalently if it is stable under the projection maps that extract each graded component. The homogeneous hull is the analogue, for ideals, of the "homogeneous closure" operation: take all graded components of all elements of `I` and form the ideal they generate.

VTask.homogeneousHull : {ι : Type u_1} -> {σ : Type u_2} -> {A : Type u_3} -> [Semiring A] -> [DecidableEq ι] -> [AddMonoid ι] -> [SetLike σ A] -> [AddSubmonoidClass σ A] -> (𝒜 : ι → σ) -> [GradedRing 𝒜] -> (I : Ideal A) -> HomogeneousIdeal 𝒜

The type `ι` is the **index type** for the grading (typically `ℕ` or `ℤ` or a more general additive monoid). The type `σ` is the **type of graded pieces** (e.g., submodules or additive subgroups). The type `A` is the **underlying ring**. The argument `𝒜 : ι → σ` is the **grading data** itself: it assigns to each index `i : ι` the `i`-th graded component of `A`. The argument `I : Ideal A` is the **ideal whose homogeneous hull is to be formed**; it need not itself be homogeneous.

## Conventions

There are no special junk-value or out-of-domain conventions for this definition: it is defined for every ideal `I` in every graded ring, so no inputs are excluded or treated specially at a boundary.

## Worked examples

- Claim: For any ideal `I`, the original ideal `I` is contained in the underlying ideal of `VTask.homogeneousHull 𝒜 I`.

- Claim: If `I` is already a homogeneous ideal, then the underlying ideal of `VTask.homogeneousHull 𝒜 I` equals `I` itself — the hull is idempotent on homogeneous ideals.

- Claim: `VTask.homogeneousHull 𝒜` is monotone: if `I ≤ J` as ideals then `VTask.homogeneousHull 𝒜 I ≤ VTask.homogeneousHull 𝒜 J`.

- Claim: `VTask.homogeneousHull 𝒜 I` equals the infimum (intersection) of all homogeneous ideals that contain `I`, confirming it is truly the smallest such homogeneous ideal.

## Boundaries

- **Zero ideal**: `VTask.homogeneousHull 𝒜 ⊥` is the zero homogeneous ideal, since the only element is `0`, whose every graded component is `0`.
- **Unit ideal**: `VTask.homogeneousHull 𝒜 ⊤` is the top homogeneous ideal `⊤`, since `1 ∈ I` implies its components generate the whole ring.
- **Already homogeneous**: If `I` is homogeneous, `VTask.homogeneousHull 𝒜 I` has the same underlying ideal as `I`; the operation is the identity on homogeneous ideals.
- **Trivial grading**: If the grading is concentrated in degree `0` (everything sits in a single piece), every ideal is automatically homogeneous, so the hull of any ideal is the ideal itself.

## Not to be confused with

- `HomogeneousIdeal.toIdeal`: the forgetful map from a `HomogeneousIdeal` back to an `Ideal`; this goes in the opposite direction from `homogeneousHull`.
- `Ideal.IsHomogeneous`: the *predicate* asserting that an ideal is homogeneous, as opposed to the *construction* of the homogeneous hull.
- `GradedRing.proj 𝒜 i`: the projection of a single element onto its `i`-th graded component; the hull uses all such projections but is a global ideal-level construction rather than an element-level one.

## VTask.FG

### Object

A subalgebra `S` of an `R`-algebra `A` is **finitely generated** if there is a finite set of elements of `A` whose `R`-algebra adjunction equals `S` exactly. In other words, `S` can be built from a finite list of generators together with all the ring operations (addition, multiplication, scalar multiplication by `R`) and the image of the unit map.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.FG : {R : Type u} -> {A : Type v} -> [CommSemiring R] -> [Semiring A] -> [Algebra R A] -> (S : Subalgebra R A) -> Prop
<!-- PINNED-SIGNATURE:END -->


`VTask.FG : {R : Type u} -> {A : Type v} -> [CommSemiring R] -> [Semiring A] -> [Algebra R A] -> (S : Subalgebra R A) -> Prop`

The implicit type `R` is the coefficient semiring (base ring); `A` is the ambient `R`-algebra. The three typeclass arguments require `R` to be a commutative semiring, `A` to be a semiring, and `A` to carry an `R`-algebra structure. The explicit argument `S` is the subalgebra of `A` over `R` whose finite-generation is being asserted.

### Conventions

There are no junk-value or edge-case conventions to declare: `VTask.FG` is a well-formed `Prop` for every subalgebra `S` in the given algebraic context, and no distinguished behaviour is imposed at boundary inputs.

### Worked Examples

- Claim: The top subalgebra `⊤ : Subalgebra ℚ ℚ` is finitely generated (it is generated by the empty finite set, since adjoining nothing over a field with unit gives everything).

- Claim: For any commutative semiring `R` and any `R`-algebra `A`, the scalar image subalgebra `⊥ : Subalgebra R A` (the copy of `R` inside `A`) satisfies `VTask.FG (⊥ : Subalgebra R A)`, witnessed by the empty finset (adjoining the empty set over `R` gives exactly the image of `R`).

- Claim: If `S` and `T` are finitely generated subalgebras of `A` over `R`, then their join (the smallest subalgebra containing both) is also finitely generated, since the union of the two finite generating sets generates the join.

- Claim: A subalgebra generated by a single element `a : A` satisfies `VTask.FG` (witnessed by the singleton finset `{a}`).

### Boundaries

- The empty finset is a valid witness: `Algebra.adjoin R ∅ = ⊥`, so the bottom subalgebra is always finitely generated.
- The property is existential; it does not record the actual generating set, only that one exists.
- Working over a semiring (not necessarily a ring) is allowed: no subtraction or negation is required.
- `VTask.FG` makes sense even when `A` is not commutative as an `R`-algebra, since `A` is only required to be a `Semiring` with an algebra structure.

### Not to be confused with

- `Submodule.FG`: finite generation of a submodule as an `R`-module, which only adjoins under addition and scalar multiplication, not multiplication of elements.
- `Ideal.FG` (or `Submodule.FG` applied to an ideal): an ideal being finitely generated as a module, a strictly weaker condition than being a finitely generated subalgebra.
- `Module.Finite` / `Algebra.FiniteType`: `Algebra.FiniteType R A` asserts that `A` itself (the top subalgebra) is finitely generated over `R`, whereas `VTask.FG S` applies to an arbitrary subalgebra `S`.

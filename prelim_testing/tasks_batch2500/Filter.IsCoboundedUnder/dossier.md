## VTask.IsCoboundedUnder

### Object

`VTask.IsCoboundedUnder r f u` is the proposition that the net or sequence defined by the map `u` along the filter `f` is **frequently bounded** with respect to the relation `r`. More precisely, it asserts that the image of `f` under `u` does not escape to infinity in the direction indicated by `r`: there exists some element `a` in the codomain such that `r a (u x)` holds for **frequently** many `x` in `f` (i.e., for a set of `x`-values that is not negligible with respect to `f`). Typical instances are `r = (· ≤ ·)` (the values `u x` are frequently at least as large as some fixed bound, so they do not drift to `−∞`) and `r = (· ≥ ·)` (the values `u x` are frequently at most as large as some fixed bound, so they do not drift to `+∞`).

```
VTask.IsCoboundedUnder : {α : Type u_1} -> {β : Type u_2} -> (r : α → α → Prop) -> (f : Filter β) -> (u : β → α) -> Prop
```

The first explicit argument `r` is the binary relation on the codomain type `α` that specifies the "direction of infinity" being avoided — typically a preorder relation such as `≤` or `≥`. The second argument `f` is the filter on the index type `β` that encodes the notion of "most" or "eventually", determining which subsets of indices are considered large. The third argument `u` is the map from index type `β` to value type `α` whose behaviour along `f` is under scrutiny.

### Conventions

There are no junk-value or out-of-domain conventions declared for this definition: it is a universally-quantified `Prop` over all choices of `r`, `f`, and `u`, and every combination is a well-formed (possibly false) proposition.

### Worked examples

- Claim: If `u : ℕ → ℤ` satisfies `u n = n` for all `n`, then `VTask.IsCoboundedUnder (· ≥ ·) Filter.atTop u` holds, because the values grow without bound above and are frequently (in fact eventually) bounded below by any fixed integer.

- Claim: For the constant map `u : ℕ → ℝ` defined by `u n = 0`, `VTask.IsCoboundedUnder (· ≤ ·) Filter.atTop u` holds, since every value equals `0`, which serves as a lower bound that is attained on every set in the filter.

- Claim: If `f : Filter β` is a `NeBot` filter and `u : β → α` satisfies `IsBoundedUnder (· ≥ ·) f u` (i.e., the values are eventually bounded below), then `VTask.IsCoboundedUnder (· ≤ ·) f u` holds (the values do not tend to `−∞`).

- Claim: `VTask.IsCoboundedUnder (· ≤ ·) f u` holds whenever there exists `a : α` such that `∃ᶠ x in f, a ≤ u x` (the values are frequently at least `a`).

### Boundaries

- When `f` is the **bottom filter** (`⊥`, the filter that contains every set), every proposition about it is trivially true, including coboundedness, because the frequently-quantifier over `⊥` is vacuous.
- When the relation `r` is the **empty relation** (never holds), `IsCoboundedUnder r f u` is false for any non-trivial filter, since no element can serve as the required frequent bound.
- When `f` is a **principal filter** generated by a singleton `{b}`, the condition reduces to the existence of some `a` with `r a (u b)`, which is a purely pointwise condition on `u b`.
- The property is **not symmetric** in `r` and its flip: `IsCoboundedUnder (· ≤ ·) f u` and `IsCoboundedUnder (· ≥ ·) f u` are independent and correspond to the sequence not drifting to `−∞` and not drifting to `+∞`, respectively.
- For a **non-bot filter** (`NeBot f`) and a transitive relation `r`, if `u` is bounded in the `r`-direction (`IsBoundedUnder r f u`), then `u` is cobounded in the flipped direction (`IsCoboundedUnder (flip r) f u`).

### Not to be confused with

- **`IsBoundedUnder r f u`**: asserts that `u` is *eventually* bounded with respect to `r` (the values eventually satisfy `r (u x) a` for some fixed `a`), i.e., the dual "bounded above/below" property rather than "frequently bounded".
- **`IsCobounded r f`**: the underlying filter-level coboundedness predicate applied directly to a filter `f` on `α`; `IsCoboundedUnder r f u` is precisely `IsCobounded r (map u f)`, so the "Under" variant is the version pulled back through a map.
- **`Tendsto u f (Filter.atTop)`**: asserts that `u` *tends to infinity* along `f`, which is the opposite of coboundedness — a sequence tending to `+∞` is not `IsCoboundedUnder (· ≥ ·) f u`.

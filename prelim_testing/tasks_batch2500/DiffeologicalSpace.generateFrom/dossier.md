## Object

`VTask.generateFrom g` is the **smallest diffeological space** on a type `X` whose set of plots contains every element of `g`. Concretely, a diffeological space on `X` is a collection of *plots* — smooth maps from open subsets of Euclidean spaces into `X` — satisfying three axioms (constant maps are plots, plots are closed under smooth reparametrisation, and the smooth structure is local). Given a generating set `g` of candidate plots (each paired with the dimension of its domain), `VTask.generateFrom g` is the intersection of all diffeological spaces whose plot-collection contains `g`: it is their greatest lower bound in the lattice of diffeological structures ordered by coarseness.

`VTask.generateFrom : {X : Type u_1} -> (g : Set ((n : ℕ) × (EuclideanSpace ℝ (Fin n) → X))) -> DiffeologicalSpace X`

`X` is the carrier type on which the diffeological space is built. The argument `g` is the generating set of plots: each element of `g` is a dependent pair `⟨n, p⟩` consisting of a natural number `n` (the dimension of the Euclidean source space) and a map `p : EuclideanSpace ℝ (Fin n) → X` (the plot itself). These are the "seeds" from which the full diffeological structure is generated.

## Conventions

There are no special junk-value or edge conventions for this definition: it is total and well-defined for every set `g`, including the empty set.

## Worked examples

- Claim: Generating from the empty set yields the indiscrete diffeology (the coarsest diffeological structure on `X`), whose plots consist of exactly the constant maps and everything derivable from them by the axioms.

- Claim: If `g` is already the plot-set of some diffeological space `D`, then every plot of `VTask.generateFrom g` is also a plot of `D`, i.e., `VTask.generateFrom g` is coarser than or equal to `D`.

- Claim: For any set `g`, every plot that belongs to any diffeological space containing all of `g` also belongs to `VTask.generateFrom g` — that is, `VTask.generateFrom g` is indeed the *smallest* such structure.

- Claim: If `g ⊆ h`, then every plot of `VTask.generateFrom g` is a plot of `VTask.generateFrom h`, i.e., generation is monotone with respect to inclusion of generating sets.

## Boundaries

- **Empty generating set**: `VTask.generateFrom ∅` is the coarsest possible diffeological space on `X`, generated solely by the three axioms (constant plots, reparametrisation, and locality) with no extra data.
- **Generating set equal to all plots of a fixed diffeology**: If `g` is exactly the plot-set of some `D : DiffeologicalSpace X`, then `VTask.generateFrom g = D`.
- **Generating set larger than any single diffeology**: If `g` is not contained in the plots of any single diffeological structure (which cannot happen, since the indiscrete/finest diffeology always contains everything), the construction still yields a valid diffeological space.
- **Dimension-0 plots**: A plot `⟨0, p⟩` in `g` is a map from `EuclideanSpace ℝ (Fin 0)` (a single-point space) into `X`; it behaves exactly like a constant plot and adds no extra structure beyond specifying a particular point.

## Not to be confused with

- **`DiffeologicalSpace.iInf` / the infimum in the lattice of diffeological spaces**: The lattice infimum of a family of diffeological spaces takes the intersection of their plot-sets; `VTask.generateFrom g` instead takes the intersection of all diffeological spaces *containing* `g`, which is the lattice `iInf` over a different family.
- **The discrete diffeology**: The finest diffeological structure (all maps are plots) is the *largest* element of the lattice, not the structure generated by any set; do not confuse "generated by a large set" with "discrete".
- **`DiffeologicalSpace.instTop` (the indiscrete/coarsest diffeology)**: Generating from the empty set gives the coarsest diffeology (only axiom-forced plots), but `VTask.generateFrom` is a general construction, not restricted to this extreme case.

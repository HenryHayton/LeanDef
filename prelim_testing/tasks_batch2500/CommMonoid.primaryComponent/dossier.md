## Object

The **p-primary component** of a commutative monoid `G` is the submonoid consisting of all elements whose order divides some power of `p`. Concretely, an element `g ∈ G` belongs to this submonoid if and only if there exists a natural number `k` such that `g^(p^k) = 1`. When `G` is written additively and `p` is prime, these are precisely the elements whose additive order is a power of `p` (elements of *p-power order*), i.e., the classical *p-primary* or *p-torsion* part of the group.

`VTask.primaryComponent : (G : Type u_1) -> [CommMonoid G] -> (p : ℕ) -> Submonoid G`

The first argument `G` is the ambient commutative monoid whose elements are examined. The instance argument supplies the commutative monoid structure on `G`. The argument `p` is the prime (or, more generally, any natural number) that specifies which power-of-`p` roots of unity are collected.

## Conventions

The definition is stated for any natural number `p`, not just primes; when `p` is not prime the resulting submonoid may behave in unexpected ways (e.g., for `p = 1` every element satisfies `g^(1^k) = g^1 = 1` only if `g = 1`, giving the trivial submonoid, while for `p = 0` only elements satisfying `g^1 = 1` after `p^k = 0` could match). The meaningful mathematical content is recovered when `p` is a prime number.

## Worked examples

- Claim: The identity element `(1 : G)` belongs to `VTask.primaryComponent G p` for any commutative monoid `G` and any `p`.

- Claim: In `ZMod 4` (written multiplicatively as a `CommMonoid`), the element `3 : ZMod 4` (which satisfies `3^2 = 1` in the multiplicative sense, i.e., order 2) belongs to `VTask.primaryComponent (ZMod 4) 2`, since `2^1 = 2` and `3^2 = 1`.

- Claim: In the integers-mod-8 monoid under multiplication, the element `1` belongs to `VTask.primaryComponent (ZMod 8) 3` with witness `k = 0`, since `1^(3^0) = 1^1 = 1`.

- Claim: If `g : G` satisfies `g ^ (p ^ k) = 1` for some `k`, then `g` is a member of `VTask.primaryComponent G p`.

## Boundaries

- **`p = 0`**: `p^k = 0` for all `k ≥ 1`, so the condition `g^(p^k) = 1` becomes `g^0 = 1`, which is always true. Hence every element belongs to `VTask.primaryComponent G 0`.
- **`p = 1`**: `p^k = 1` for all `k`, so the condition becomes `g^1 = 1`, meaning only the identity element belongs. The result is the trivial submonoid `{1}`.
- **Trivial monoid**: In the trivial monoid `{1}`, the primary component is the whole (trivial) monoid regardless of `p`.
- **The submonoid always contains `1`**: By choosing `k = 0`, one has `g^(p^0) = g^1 = g`, so this witnesses membership only for `g = 1`; membership of `1` is witnessed by `k` arbitrary since `1^n = 1`.
- **Closure under multiplication**: The submonoid is closed under the monoid operation: if `g^(p^m) = 1` and `h^(p^n) = 1`, then `(gh)^(p^(m+n)) = 1`, using commutativity and the fact that `p^(m+n)` is divisible by both `p^m` and `p^n`.

## Not to be confused with

- **`Submonoid.powers p`**: The submonoid *generated by* a single element `p` (powers of `p` in `G`), not the collection of elements annihilated by powers of `p`.
- **`AddSubgroup` p-primary component**: The additive analogue (mentioned in the docstring) where the condition is `p^k • g = 0`; `VTask.primaryComponent` is the *multiplicative* version.
- **`p`-Sylow subgroup**: In finite groups, the Sylow `p`-subgroup is a specific maximal `p`-subgroup; while related, it is a subgroup of a finite group chosen by Sylow's theorem, not defined by the universal property of containing all `p`-power-order elements.

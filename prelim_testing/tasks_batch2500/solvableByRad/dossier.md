## Object

`VTask.solvableByRad F E` is the intermediate field of elements of `E` that are **solvable by radicals** over `F`. Informally, it is the smallest subfield of `E` that contains `F` and is closed under the operation of extracting `n`-th roots: if `x ∈ E` and `xⁿ` already lies in the field (for some positive integer `n`), then `x` itself belongs to the field. In classical terms, this is the subfield of `E` generated by all elements expressible via iterated field operations (+, −, ×, ÷) and extraction of roots from elements of `F`.

VTask.solvableByRad : (F : Type u_1) -> (E : Type u_2) -> [Field F] -> [Field E] -> [Algebra F E] -> IntermediateField F E

`F` is the base field (the ground field over which solvability is measured). `E` is the ambient field extension in which roots are sought. The `Field` instances equip each type with its field structure, and the `Algebra F E` instance makes `E` an `F`-algebra, providing the embedding of `F` into `E`. The result is an `IntermediateField F E`, i.e., a subfield of `E` that contains the image of `F`.

## Conventions

The root-closure condition is stated for all nonzero natural numbers `n`: a subfield is considered closed under radicals if for every `n ≠ 0` and every `x ∈ E`, whenever `xⁿ ∈ s` it follows that `x ∈ s`. The exponent `0` is excluded (since `x⁰ = 1` for all `x`, requiring `x ∈ s` whenever `1 ∈ s` would be vacuously trivial or pathological). This convention is baked into the closure condition defining membership.

## Worked examples

- Claim: Every element of `F` (i.e., every element in the image of the algebra map `F → E`) belongs to `VTask.solvableByRad F E`.

- Claim: If `x ∈ E`, `n ≠ 0`, and `xⁿ ∈ VTask.solvableByRad F E`, then `x ∈ VTask.solvableByRad F E` (the field is closed under taking `n`-th roots).

- Claim: Every element of `VTask.solvableByRad F E` is algebraic over `F`; in particular, `VTask.solvableByRad F E` is contained in the algebraic closure of `F` in `E`.

- Claim: For any element `x ∈ VTask.solvableByRad F E`, the Galois group of the minimal polynomial of `x` over `F` is a solvable group.

## Boundaries

- **Minimality**: `VTask.solvableByRad F E` is the *smallest* intermediate field with the radical-closure property. Any intermediate field `s` that is closed under `n`-th roots (for all `n ≠ 0`) contains `VTask.solvableByRad F E`.
- **Algebraicity**: All elements are algebraic (and integral) over `F`; the field does not contain transcendental elements over `F`.
- **Ambient constraint**: Elements solvable by radicals are drawn from `E`; if `E` itself is small (e.g., a finite extension), `VTask.solvableByRad F E` may equal a proper subfield or even `F` itself.
- **Containment in algebraic closure**: `VTask.solvableByRad F E` is always contained in the algebraic closure of `F` inside `E`.
- **`n = 0` exclusion**: The root-closure property is only enforced for `n ≠ 0`; the case `n = 0` is excluded by hypothesis.

## Not to be confused with

- **`IsSolvableByRad F x`** (if it exists): a predicate asserting that a single element is solvable by radicals, as opposed to the subfield of all such elements.
- **`algebraicClosure F E`**: the full algebraic closure of `F` in `E`, which is generally larger; `VTask.solvableByRad F E` is contained in it but equality does not hold in general (e.g., over `ℚ`, algebraic numbers like roots of degree-5 polynomials with non-solvable Galois group are algebraic but not solvable by radicals).
- **`IntermediateField.adjoin`**: the field generated by adjoining a *specific* set of elements, rather than the closure under all radical operations.

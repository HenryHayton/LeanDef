## VTask.eqLocusS

### Object

Given two semiring homomorphisms `f` and `g` from a semiring `R` to a semiring `S`, `VTask.eqLocusS f g` is the **equalizer subsemiring** of `f` and `g`: the largest sub-semiring of `R` consisting precisely of those elements `x` on which `f` and `g` agree, i.e., the set `{ x : R | f x = g x }` equipped with the sub-semiring structure inherited from `R`.

### Signature

VTask.eqLocusS : {R : Type u} -> {S : Type v} -> [NonAssocSemiring R] -> [NonAssocSemiring S] -> (f g : R →+* S) -> Subsemiring R
<!-- PINNED-SIGNATURE:END -->


`VTask.eqLocusS : {R : Type u} -> {S : Type v} -> [NonAssocSemiring R] -> [NonAssocSemiring S] -> (f g : R →+* S) -> Subsemiring R`

The implicit type arguments `R` and `S` are the source and target types, inferred from context. The two typeclass arguments supply the non-associative semiring structures on `R` and `S` respectively, and are typically found automatically. The first explicit argument `f` is the first semiring homomorphism from `R` to `S`; the second explicit argument `g` is the second semiring homomorphism from `R` to `S`. The result is a `Subsemiring R`, i.e., a sub-semiring of the source `R`.

### Conventions

No special junk-value or boundary conventions are declared for this definition: it is total on all pairs of semiring homomorphisms and always produces a valid `Subsemiring R`.

### Worked examples

- Claim: An element `x : R` belongs to `VTask.eqLocusS f g` if and only if `f x = g x`.

- Claim: If `f = g` (the two homomorphisms are equal), then every element of `R` belongs to `VTask.eqLocusS f g`, so its carrier equals the top subsemiring of `R`.

- Claim: The zero element `0 : R` always belongs to `VTask.eqLocusS f g`, because any semiring homomorphism sends `0` to `0`, so `f 0 = 0 = g 0`.

- Claim: The one element `1 : R` always belongs to `VTask.eqLocusS f g`, because any semiring homomorphism sends `1` to `1`, so `f 1 = 1 = g 1`.

- Claim: If `x` and `y` both belong to `VTask.eqLocusS f g`, then so do `x + y` and `x * y`, reflecting the closure properties that make the equalizer a genuine sub-semiring.

### Boundaries

- When `f = g`, the equalizer is all of `R` (every element satisfies `f x = g x` trivially). The result is still a well-formed `Subsemiring R`, equal to the top element.
- When `f` and `g` agree on no element other than `0` and `1`, the equalizer subsemiring is exactly `{0, 1}` (the smallest possible sub-semiring generated by those distinguished elements), provided `0 ≠ 1`; the definition handles this seamlessly.
- The construction works for any `NonAssocSemiring`; commutativity, associativity of multiplication, and the existence of additive inverses are not required.
- There is no requirement that `f` or `g` be surjective, injective, or otherwise special.

### Not to be confused with

- `RingHom.eqLocus` (or an analogous `Subring` variant): the equalizer packaged as a `Subring` rather than a `Subsemiring`; requires stronger ring structure (in particular additive inverses).
- The equalizer of two monoid homomorphisms `(f : R →* S).eqLocusM g`: this gives only a `Submonoid` of the multiplicative structure of `R`, ignoring the additive structure entirely.
- The equalizer of two additive-monoid homomorphisms `(f : R →+ S).eqLocusM g`: this gives only an `AddSubmonoid` of `R`, ignoring the multiplicative structure entirely.

## VTask.commutatorSet

### Object

Given a group `G`, `VTask.commutatorSet G` is the subset of `G` consisting of all *commutator elements*, i.e., every element of `G` that can be written in the form `⁅g₁, g₂⁆ = g₁ * g₂ * g₁⁻¹ * g₂⁻¹` for some (not necessarily distinct) `g₁, g₂ ∈ G`. This is the set of "raw" commutators; it is generally not a subgroup, but it generates the commutator subgroup (derived subgroup) of `G`.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.commutatorSet : (G : Type u_1) -> [Group G] -> Set G
<!-- PINNED-SIGNATURE:END -->


`(G : Type u_1) -> [Group G] -> Set G`

The first argument is the ambient group type `G`. The instance argument supplies the group structure on `G`. The result is a subset of `G`.

### Conventions

No special junk-value or edge-case conventions are declared for this definition: it is a straightforwardly total set-valued function whose membership condition is simply an existential quantifier over pairs of group elements.

### Worked examples

- Claim: The identity element of any group `G` belongs to `VTask.commutatorSet G`, since `⁅1, 1⁆ = 1`.

- Claim: In an abelian group `G`, every commutator equals the identity, so `VTask.commutatorSet G = {1}`.

- Claim: If `g ∈ VTask.commutatorSet G`, then there exist `g₁ g₂ : G` with `g₁ * g₂ * g₁⁻¹ * g₂⁻¹ = g`.

- Claim: For the symmetric group `S₃`, the commutator set is exactly the set of even permutations reachable as single commutators; in particular it is a proper subset of the alternating group `A₃` together with some transpositions.

### Boundaries

- **Trivial group**: The commutator set of the trivial group `{1}` is `{1}`, since the only commutator is `⁅1, 1⁆ = 1`.
- **Abelian groups**: In any abelian group, `⁅g₁, g₂⁆ = 1` for all `g₁, g₂`, so the commutator set is exactly `{1}` (the singleton containing only the identity).
- **Non-closure**: The commutator set need not be closed under the group operation; the subgroup it generates is the commutator (derived) subgroup, which can be strictly larger.
- **Inverse membership**: If `⁅g₁, g₂⁆ = g`, then `⁅g₂, g₁⁆ = g⁻¹`, so inverses of commutators are also commutators. Thus the commutator set is closed under inverses.
- **Conjugation**: Conjugates of commutators are commutators, so the commutator set is closed under conjugation by elements of `G`.

### Not to be confused with

- **Commutator subgroup (derived subgroup)**: The subgroup *generated by* all commutators; this may be strictly larger than `VTask.commutatorSet G` when products of commutators are not themselves commutators.
- **`⁅H, K⁆` (commutator of two subgroups)**: The subgroup generated by all commutators `⁅h, k⁆` with `h ∈ H`, `k ∈ K`; `VTask.commutatorSet G` is the special case of elements (not the subgroup) for the whole group.
- **`commutator g₁ g₂`**: The single commutator element `⁅g₁, g₂⁆` for fixed `g₁, g₂`; `VTask.commutatorSet G` collects *all* such elements as `g₁, g₂` range over `G`.

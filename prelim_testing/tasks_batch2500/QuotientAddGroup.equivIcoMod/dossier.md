## Object

`VTask.equivIcoMod hp a` is a canonical bijection (an equivalence of types) between the quotient group `α ⧸ ℤ•p` — that is, the additive group `α` modulo the cyclic subgroup generated by `p` — and the half-open interval `[a, a+p)` inside `α`. It witnesses the well-known fact that every coset of `ℤ•p` in an Archimedean ordered group contains exactly one representative in any window of length `p`.

`{α : Type u_1} -> [AddCommGroup α] -> [LinearOrder α] -> [IsOrderedAddMonoid α] -> [hα : Archimedean α] -> {p : α} -> (hp : 0 < p) -> (a : α) -> α ⧸ AddSubgroup.zmultiples p ≃ ↑(Set.Ico a (a + p))`

The type class arguments supply the necessary algebraic and order-theoretic structure on the carrier type `α`. The implicit argument `p` is the period (the generator of the subgroup being quotiented out). The explicit argument `hp` is the proof that the period `p` is strictly positive, which is essential for the interval `[a, a+p)` to be non-degenerate and for the bijection to exist. The explicit argument `a` is the left endpoint of the representative interval; varying `a` shifts the fundamental domain.

## Conventions

There are no declared junk-value conventions for this definition: it is a total equivalence defined for all valid inputs satisfying the stated positivity hypothesis, and the codomain is already constrained to the interval `[a, a+p)` by the type.

## Worked examples

- Claim: For `α = ℝ`, `p = 1`, `a = 0`, and the coset of `0.3 : ℝ`, the image under `VTask.equivIcoMod hp 0` is `⟨toIcoMod hp 0 0.3, _⟩ = ⟨0.3, _⟩` (i.e., `0.3` already lies in `[0,1)` and is its own canonical representative).

- Claim: For `α = ℝ`, `p = 1`, `a = 0`, the element `0 : ℝ` (as a coset representative) maps to `⟨toIcoMod hp 0 0, _⟩`; since `0 ∈ [0,1)`, this representative is `0`.

- Claim: The inverse map `(VTask.equivIcoMod hp a).symm` sends each element `⟨x, hx⟩ ∈ [a, a+p)` to the coset `↑x` in `α ⧸ AddSubgroup.zmultiples p`.

- Claim: The composition `(VTask.equivIcoMod hp a).symm ∘ (VTask.equivIcoMod hp a)` is the identity on `α ⧸ AddSubgroup.zmultiples p` (by the `Equiv` axioms).

## Boundaries

- The positivity hypothesis `hp : 0 < p` is strictly required. If `p = 0`, then `ℤ•p` is the trivial subgroup `{0}`, the interval `[a, a+0)` is empty, and the bijection cannot exist. The definition is therefore undefined at `p = 0`.
- The left endpoint `a` may be any element of `α`, including negative values. Changing `a` shifts the window but the equivalence remains valid; different values of `a` give different but canonically isomorphic fundamental domains.
- For `α = ℤ` (or other discrete ordered groups), the interval `[a, a+p)` contains exactly `p` integer points, consistently with the fact that `ℤ ⧸ pℤ` has order `p`.
- Elements of `α` that already lie in `[a, a+p)` are sent to themselves (as subtypes) under the forward map.

## Not to be confused with

- `QuotientAddGroup.equivIocMod`: an analogous equivalence using the half-open interval `(a, a+p]` (right-closed) instead of `[a, a+p)`.
- `toIcoMod hp a`: the bare function `α → α` (not an equiv) selecting the unique representative in `[a, a+p)`, which `VTask.equivIcoMod` packages into a genuine bijection with a typed codomain.
- `AddCircle.equivIco`: a related construction for the circle group `α ⧸ ℤ•p` viewed as a type alias, which may differ in bundling or definitional equality.

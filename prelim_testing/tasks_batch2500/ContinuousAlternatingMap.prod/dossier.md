## VTask.prod

### Object

Given two continuous alternating multilinear maps `f` and `g` from the same source module `M` (indexed by `ι`) to modules `N` and `N'` respectively, `VTask.prod f g` is the continuous alternating multilinear map that sends each tuple of inputs simultaneously through `f` and `g`, producing an element of the Cartesian product `N × N'`. Concretely, it is the map `v ↦ (f v, g v)`, which inherits multilinearity, the alternating property (vanishing whenever two inputs coincide), and continuity from its two components.

`VTask.prod : {R : Type u_1} -> {M : Type u_2} -> {N : Type u_4} -> {N' : Type u_5} -> {ι : Type u_6} -> [Semiring R] -> [AddCommMonoid M] -> [Module R M] -> [TopologicalSpace M] -> [AddCommMonoid N] -> [Module R N] -> [TopologicalSpace N] -> [AddCommMonoid N'] -> [Module R N'] -> [TopologicalSpace N'] -> (f : M [⋀^ι]→L[R] N) -> (g : M [⋀^ι]→L[R] N') -> M [⋀^ι]→L[R] (N × N')`

The ring `R` is the scalar semiring shared by all modules. The module `M` is the common domain, topologized appropriately. The modules `N` and `N'` are the two target modules (each an `R`-module with a topology). The index type `ι` parameterises the arity of the multilinear maps. The argument `f` is the first component map, producing values in `N`. The argument `g` is the second component map, producing values in `N'`.

### Conventions

No special junk-value or boundary conventions are declared for this definition: it is a total construction on well-typed inputs and every continuous alternating map pair yields a valid product map.

### Worked examples

- Claim: Applying `VTask.prod f g` to a tuple `v` yields the pair `(f v, g v)` — that is, the first projection of `(VTask.prod f g) v` equals `f v`, and the second projection equals `g v`.

- Claim: If `f` is the zero continuous alternating map and `g` is any continuous alternating map, then `VTask.prod f g` applied to any tuple `v` gives `(0, g v)`.

- Claim: The map `VTask.prod f g` is alternating: if any two entries of the input tuple coincide, the output is `(0, 0)` in `N × N'`, because both `f v = 0` and `g v = 0` individually by the alternating property.

- Claim: The construction is additive in the first argument in the sense that `VTask.prod (f₁ + f₂) g` and `VTask.prod f₁ g + VTask.prod f₂ g` agree pointwise on all inputs.

### Boundaries

- When `ι` is empty (arity zero), both `f` and `g` are just constant maps; `VTask.prod f g` is then the constant map returning the pair of their respective constant values, and the alternating condition is vacuous.
- When `N'` is the trivial module, `VTask.prod f g` essentially recovers `f` up to a trivial second component.
- When `f = g`, the product map sends every input `v` to the diagonal element `(f v, f v)` in `N × N`.
- Continuity of the product map is automatic because the product topology on `N × N'` is the one generated by projections, and each component is already continuous.

### Not to be confused with

- `ContinuousMultilinearMap.prod`: the analogous pairing for continuous *multilinear* maps, which does not impose the alternating (antisymmetry) condition.
- `AlternatingMap.prod`: the purely algebraic (non-topological) version that pairs two alternating maps without requiring or preserving continuity.
- `ContinuousAlternatingMap.pi`: a generalisation that pairs a whole family of continuous alternating maps indexed by some type, rather than just two maps into a binary product.

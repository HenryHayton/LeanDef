## VTask.multiples

### Object

`VTask.multiples x` is the additive submonoid of `A` consisting of all non-negative integer multiples of a fixed element `x`. Concretely, its underlying set is `{ n • x | n : ℕ }` — that is, `0 • x = 0`, `1 • x = x`, `2 • x = x + x`, and so on. It is the smallest additive submonoid of `A` that contains `x`.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.multiples : {A : Type u_2} -> [AddMonoid A] -> (x : A) -> AddSubmonoid A
<!-- PINNED-SIGNATURE:END -->


`VTask.multiples : {A : Type u_2} -> [AddMonoid A] -> (x : A) -> AddSubmonoid A`

The implicit type argument `A` is the ambient additive monoid. The typeclass argument `[AddMonoid A]` supplies the additive monoid structure (identity element `0` and associative addition). The explicit argument `x` is the generating element whose non-negative integer multiples form the submonoid.

### Conventions

The `n` in `n • x` ranges over the natural numbers `ℕ`, so negative multiples are not included; in particular the element `0 • x = 0` (the identity of `A`) is always a member, consistent with every submonoid containing the identity.

### Worked examples

- Claim: The element `3 • x` belongs to `VTask.multiples x` for any `x : A` in an `AddMonoid A`, witnessed by `n = 3`.

- Claim: In `ℕ` with `x = 2`, the element `6` belongs to `VTask.multiples 2`, since `6 = 3 • 2`.

- Claim: In `ℕ` with `x = 2`, the zero element `0` belongs to `VTask.multiples 2`, since `0 = 0 • 2`.

- Claim: For any `AddMonoid A` and `x : A`, the element `x` itself (i.e., `1 • x`) belongs to `VTask.multiples x`.

### Boundaries

- When `x = 0` (the identity), every element `n • 0 = 0`, so `VTask.multiples 0` is the trivial submonoid `{0}`.
- When `A = ℕ` and `x = 1`, `VTask.multiples 1` is all of `ℕ` (viewed as an `AddSubmonoid ℕ`), since every natural number equals `n • 1` for some `n`.
- The submonoid is not required to be closed under subtraction, so it is generally not a subgroup — it is precisely a submonoid, not a subgroup.
- Because `n` ranges over `ℕ` (not `ℤ`), the result always contains `0` but need not contain additive inverses.

### Not to be confused with

- `AddSubgroup.zmultiples x`: the additive subgroup generated by `x`, which uses `ℤ`-multiples (including negatives) instead of `ℕ`-multiples.
- `Submonoid.powers x`: the multiplicative analogue, consisting of all non-negative integer powers `x ^ n`, for a `Monoid`.
- `AddSubmonoid.closure {x}`: the additive submonoid closure of the singleton `{x}`, which coincides with `VTask.multiples x` but is expressed via a closure operator rather than an explicit set of multiples.

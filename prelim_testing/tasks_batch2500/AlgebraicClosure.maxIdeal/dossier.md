## VTask.maxIdeal

### Object

Given a field `k`, `VTask.maxIdeal k` is a specific maximal ideal of the multivariate polynomial ring `MvPolynomial (AlgebraicClosure.Vars k) k` (polynomials over `k` in the variables indexed by `AlgebraicClosure.Vars k`) that contains the ideal `spanEval k` (the ideal generated by evaluating relevant polynomials). It is one maximal ideal chosen, by a nonconstructive selection principle, from the (nonempty) collection of all maximal ideals containing `spanEval k`. It is thus a proper ideal that is additionally maximal among all proper ideals, and it sits above `spanEval k` in the inclusion order.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.maxIdeal : (k : Type u) -> [Field k] -> Ideal (MvPolynomial (AlgebraicClosure.Vars k) k)
<!-- PINNED-SIGNATURE:END -->


The first argument `k` is the base field whose algebraic closure construction motivates the variable set and coefficient ring. The instance argument `[Field k]` equips `k` with its field structure.

### Conventions

The ideal is chosen nonconstructively via classical logic; no canonical or distinguished choice is made, and the result may vary between different logical environments. No junk-value conventions apply because the definition is total and well-typed for every field `k`.

### Worked examples

- Claim: `VTask.maxIdeal k` contains `spanEval k` as a sub-ideal, i.e., `spanEval k ≤ VTask.maxIdeal k`.

- Claim: `VTask.maxIdeal k` is a maximal ideal of `MvPolynomial (AlgebraicClosure.Vars k) k`, meaning it is a proper ideal not strictly contained in any other proper ideal.

- Claim: In particular, `VTask.maxIdeal k` is a proper ideal, i.e., it does not equal the whole ring `MvPolynomial (AlgebraicClosure.Vars k) k`.

### Boundaries

The construction requires that `spanEval k` is not the whole ring (i.e., `spanEval k ≠ ⊤`); this is the key hypothesis from which the existence of a maximal ideal above it is derived. The resulting ideal is guaranteed to be maximal and to contain `spanEval k`, but beyond these properties no further information about which maximal ideal was chosen is available. If one wished to change the choice, the definition would need to be altered; in particular, the value is not determined up to equality by its type.

### Not to be confused with

- `spanEval k`: the ideal that `VTask.maxIdeal k` contains; it is a generally smaller ideal, not necessarily maximal.
- The set of all maximal ideals of `MvPolynomial (AlgebraicClosure.Vars k) k`: `VTask.maxIdeal k` is merely one element of this set, chosen nonconstructively.
- The unique maximal ideal of a local ring: `MvPolynomial (AlgebraicClosure.Vars k) k` is not a local ring in general, so there is no canonical maximal ideal.

## VTask.Stable

### Object

A filtration `F` of an `R`-module `M` with respect to an ideal `I` is called **stable** (or I-adically stable) if, from some index onward, the filtration advances exactly by multiplication by `I`. Concretely, `F` is stable when there exists a threshold index `n₀` such that for every index `n ≥ n₀`, the submodule `F.N (n+1)` equals `I • F.N n`. This condition captures the idea that the filtration eventually behaves like the I-adic filtration generated by a single submodule: all later terms are obtained simply by repeated multiplication by `I`.

```
VTask.Stable : {R : Type u_1} -> {M : Type u_2} -> [CommRing R] -> [AddCommGroup M] -> [Module R M] -> {I : Ideal R} -> (F : I.Filtration M) -> Prop
```

The implicit type argument `R` is the commutative ring over which the filtration is defined. The implicit type argument `M` is the module being filtered. The instance arguments supply the commutative ring structure on `R`, the abelian group structure on `M`, and the `R`-module structure on `M`. The implicit argument `I` is the ideal that controls the filtration (the filtration is an `I`-filtration). The explicit argument `F` is the `I`-filtration of `M` whose stability is being assessed.

### Conventions

The stability condition is existential: only the existence of some threshold `n₀` is required, not its minimality or uniqueness. No convention assigns a junk value here, since the definition is a `Prop` that is simply true or false for any given filtration.

### Worked Examples

- Claim: The standard I-adic stable filtration `I.stableFiltration N` on a submodule `N` is stable for any ideal `I` and submodule `N` of `M`.

- Claim: If `F` is a stable `I`-filtration of `M` over a Noetherian ring with `M` finitely generated, and `F'` is any `I`-filtration of `M` with `F' ≤ F`, then `F'` is also stable.

- Claim: A stable filtration `F` satisfies `∃ n₀, ∀ k, F.N (n₀ + k) = I ^ k • F.N n₀`, meaning from the stabilization point onward the terms are successive powers of `I` applied to `F.N n₀`.

- Claim: For a stable filtration `F` with `F.N 0 = F'.N 0` where `F'` is also stable, there exists `n₀` such that `F.N (n + n₀) ≤ F'.N n` and `F'.N (n + n₀) ≤ F.N n` for all `n` — the two filtrations are eventually interleaved within a bounded shift.

### Boundaries

- If `I` is the unit ideal (i.e., `I = ⊤`), then `I • F.N n = F.N n` for all `n` where `F.N n` is stable under top-ideal multiplication, so stability reduces to the filtration being eventually constant.
- If `I = ⊥` (the zero ideal), then stability requires `0 = F.N (n+1)` for large `n`, meaning the filtration must eventually become the zero submodule.
- The condition only needs to hold from some `n₀` onward; behavior for small indices is unconstrained. In particular, the first few terms may behave arbitrarily.
- The standard I-adic filtration `N, I • N, I² • N, …` for any submodule `N` is always stable (witnessed by `n₀ = 0` or `n₀ = 1` depending on convention), even when `I` is not finitely generated.
- Stability is preserved under passing to smaller filtrations when `R` is Noetherian and `M` is finitely generated (Artin–Rees lemma style).

### Not to be confused with

- `Ideal.Filtration` itself: that is the broader notion of an `I`-filtration without any stability assumption; `VTask.Stable` is an additional property a filtration may or may not have.
- `Ideal.stableFiltration`: this is the *construction* of a canonical stable filtration from a submodule, not the *predicate* asserting stability.
- Eventual constancy of the filtration: a stable filtration is not required to become constant; it only requires that each step is exactly one application of `I`, so it may keep shrinking indefinitely.

## VTask.IsLinearSet

### Object

A subset `s` of an additive commutative monoid `M` is called a **linear set** if it can be written as a translate of the additive submonoid generated by some finite subset of `M`. In other words, there exist an element `a ∈ M` (the base point or offset) and a finite set `t ⊆ M` (the set of generators) such that `s` is exactly the set of all elements of the form `a + x` where `x` belongs to the submonoid generated by `t`. Linear sets are the building blocks of the semilinear sets that arise in the model-theoretic study of Presburger arithmetic: a set is semilinear if it is a finite union of linear sets.

The implicit type argument `M` is the ambient additive commutative monoid in which the set lives. The instance argument supplies the additive commutative monoid structure on `M`. The explicit argument `s` is the subset of `M` whose linearity is being asserted.

### Conventions

There are no special junk-value or boundary conventions declared for this predicate: it is a fully general existential proposition over all sets in any additive commutative monoid, and no inputs are considered degenerate or out-of-domain.

### Worked examples

- Claim: Every singleton `{a}` in an additive commutative monoid is a linear set (witnessed by base point `a` and empty generating set).

- Claim: The closure of any finitely generated additive submonoid, viewed as a set, is a linear set (witnessed by base point `0` and the given finite generating set).

- Claim: If `s` is a linear set and `a` is any element of `M`, then the translate `a +ᵥ s` is again a linear set.

- Claim: The sumset `s₁ + s₂` of two linear sets `s₁` and `s₂` is again a linear set.

- Claim: In a finitely generated additive monoid `M`, the full set `Set.univ` is a linear set.

### Boundaries

- **Empty set**: The empty set is *not* a linear set in general. A coset `a +ᵥ N` of a submonoid `N` always contains at least the element `a + 0 = a`, so it is nonempty. Hence `VTask.IsLinearSet ∅` is false whenever `M` is nonempty.
- **Whole monoid**: `Set.univ` is a linear set precisely when `M` is finitely generated as an additive monoid (i.e., `M` itself is the closure of a finite set), because then `univ` is the closure of that finite generating set, translated by `0`.
- **Single element**: Every singleton is linear, serving as a degenerate case with an empty generating set.
- **Submonoids**: A finitely generated additive submonoid, viewed as a subset, is linear (base point `0`, generators from the FG hypothesis). A submonoid that is not finitely generated need not be linear.
- **Arbitrary cosets**: If `t` is infinite but `s = a +ᵥ ⟨closure t⟩`, this does not qualify — the definition requires the generating set `t` to be **finite**.

### Not to be confused with

- **`IsSemilinearSet`**: A set is semilinear if it is a finite union of linear sets; every linear set is semilinear, but not conversely.
- **`IsProperLinearSet`**: A strictly stronger notion (proper linear set) that additionally requires the generators to be linearly independent in a suitable sense; every proper linear set is linear, but the converse can fail.
- **Affine subspaces / cosets of subgroups**: In a group, cosets of subgroups are the natural analogues, but here `M` is only a monoid (no inverses), and the "period set" is a submonoid, not a subgroup — this makes the theory of linear/semilinear sets richer and less trivial than the group case.

## VTask.inclusion

### Object

Given two star subalgebras `S₁` and `S₂` of a star algebra `A` over a commutative star semiring `R`, with `S₁` contained in `S₂`, `VTask.inclusion h` is the canonical inclusion star algebra homomorphism from `S₁` into `S₂`. It sends each element of `S₁` to the same element viewed as a member of `S₂`, preserving the ring, algebra, and star operations.

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.inclusion : {R : Type u_2} -> {A : Type u_3} -> [CommSemiring R] -> [StarRing R] -> [Semiring A] -> [StarRing A] -> [Algebra R A] -> [StarModule R A] -> {S₁ S₂ : StarSubalgebra R A} -> (h : S₁ ≤ S₂) -> ↥S₁ →⋆ₐ[R] ↥S₂
<!-- PINNED-SIGNATURE:END -->


The universe-polymorphic type parameters `R` and `A` are the scalar semiring and the ambient star algebra, respectively. The instance arguments supply the commutative semiring and star ring structures on `R`, the semiring and star ring structures on `A`, the `R`-algebra structure, and the compatible star module structure. The implicit arguments `S₁` and `S₂` are the two star subalgebras of `A`. The explicit argument `h` is a proof that `S₁ ≤ S₂`, i.e., that every element of `S₁` also belongs to `S₂`.

### Conventions

No junk-value or edge conventions are declared: the map is total and well-behaved for every valid input; there are no degenerate cases requiring special conventions.

### Worked examples

- Claim: For any element `x : S₁`, the underlying `A`-value of `VTask.inclusion h x` equals the underlying `A`-value of `x`.

- Claim: If `S₁ = S₂` (so `h : S₁ ≤ S₂` holds trivially by `le_refl`), then `VTask.inclusion h` acts as the identity on underlying elements, i.e., `(VTask.inclusion (le_refl S₁) x : A) = (x : A)` for all `x : S₁`.

- Claim: `VTask.inclusion h` preserves the star operation: for any `x : S₁`, `VTask.inclusion h (star x) = star (VTask.inclusion h x)` as elements of `S₂`.

- Claim: `VTask.inclusion h` is a star algebra homomorphism, so it maps `1 : S₁` to `1 : S₂`.

### Boundaries

- When `S₁ = S₂`, the inclusion is effectively an isomorphism (the identity), though it is typed as a homomorphism into `S₂` rather than explicitly as an isomorphism.
- When `S₁` is the bottom element (the minimal star subalgebra generated by the image of `R`), the inclusion still sends each element to itself in `S₂`.
- The map is never the zero map (unless `A` is the zero ring), since it fixes elements pointwise.
- The map on underlying `A`-elements is literally the identity function: `↑(VTask.inclusion h x) = ↑x` in `A`.

### Not to be confused with

- `StarAlgHom.id`: the identity star algebra homomorphism from a star subalgebra to itself, rather than an inclusion between two potentially distinct subalgebras.
- The coercion `S₁ → A`: this embeds `S₁` directly into the ambient algebra `A`, bypassing `S₂` entirely, whereas `VTask.inclusion h` lands in `S₂`.
- `Subalgebra.inclusion`: the analogous inclusion for ordinary subalgebras without the star structure; it does not carry or verify the `map_star'` compatibility.

## VTask.evalRingHom

### Object

`VTask.evalRingHom f i` is the *evaluation ring homomorphism* at index `i`: it takes a dependent function `g : (j : I) → f j` (a "tuple" of ring elements, one for each index) and returns its `i`-th component `g i`. In other words, it is the projection onto the `i`-th factor of the product ring `∏ i, f i`, packaged as a formal ring homomorphism (`RingHom`).

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.evalRingHom : {I : Type u} -> (f : I → Type v) -> [(i : I) → NonAssocSemiring (f i)] -> (i : I) -> ((i : I) → f i) →+* f i
<!-- PINNED-SIGNATURE:END -->


`VTask.evalRingHom : {I : Type u} -> (f : I → Type v) -> [(i : I) → NonAssocSemiring (f i)] -> (i : I) -> ((i : I) → f i) →+* f i`

- `I` is the index type parametrising the family of rings; it is implicit.
- `f` is the family of types, assigning to each index `i : I` a type `f i`.
- The instance argument `[(i : I) → NonAssocSemiring (f i)]` equips every member `f i` of the family with a non-associative semiring structure, which is required for the projection to be a ring homomorphism.
- The explicit argument `i : I` is the chosen index — the coordinate at which the evaluation takes place.
- The resulting `RingHom` maps the dependent-function type `(i : I) → f i` (the product ring) to the single factor `f i`.

### Conventions

There are no special junk-value or edge-case conventions for this definition: it is a total construction and its behaviour is uniform for every valid index `i` and every family `f`.

### Worked examples

- Claim: For the constant family `f ≡ ℤ` indexed by `Fin 3`, applying `VTask.evalRingHom` at index `1` to the tuple `![10, 20, 30]` returns `20`.

- Claim: The kernel of `VTask.evalRingHom f i` equals the ideal generated by `1 - Pi.single i 1` when the family consists of commutative rings (this is `RingHom.ker_evalRingHom` from the Mathlib library).

- Claim: For any family `f` of semirings and any index `i`, `VTask.evalRingHom f i` maps the multiplicative identity `1 : (j : I) → f j` (the tuple of all ones) to the multiplicative identity `1 : f i`.

- Claim: For any family `f` of semirings and any index `i`, `VTask.evalRingHom f i` maps the additive identity `0 : (j : I) → f j` to the additive identity `0 : f i`.

### Boundaries

- When `I` is empty (e.g., `I = Empty` or `I = Fin 0`), no index `i` can be provided, so the homomorphism simply cannot be instantiated; this is not a special case that needs handling.
- When `I` is a singleton (e.g., `I = Unit`), there is exactly one evaluation homomorphism, and it is an isomorphism between `(Unit → f ())` and `f ()`.
- When `I` is infinite (e.g., `I = ℕ`), the product ring is an infinite product, but the evaluation homomorphism is still well-defined and surjective (it has a section given by `Pi.single i`).
- The map is always surjective (every element of `f i` is the image of the function that is that element at `i` and any chosen value elsewhere), but generally not injective unless `I` is a singleton.

### Not to be confused with

- `Pi.evalMonoidHom f i` — the same projection viewed only as a monoid homomorphism, without the additive structure.
- `Pi.evalAddMonoidHom f i` — the same projection viewed only as an additive monoid homomorphism, without the multiplicative structure.
- `Pi.evalAlgHom R f i` — the evaluation map as an *algebra* homomorphism, which additionally tracks a scalar algebra structure over a base ring `R`; this is a strictly richer structure than a plain ring homomorphism.

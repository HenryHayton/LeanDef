## Object

`VTask.IsBoundedUnder r f u` is the proposition that the sequence (or net) `u` is **eventually bounded** with respect to the relation `r` along the filter `f`. Concretely, it asserts that there exists some uniform bound `a` in `α` such that, for all sufficiently large (or sufficiently typical, in the filter sense) indices `x`, the value `u x` stands in the relation `r` to `a` — i.e., `u x ≺ a` holds eventually along `f`. This is the filter-theoretic abstraction of familiar notions such as "a sequence is eventually bounded above" or "a sequence is eventually bounded below".

`VTask.IsBoundedUnder : {α : Type u_1} -> {β : Type u_2} -> (r : α → α → Prop) -> (f : Filter β) -> (u : β → α) -> Prop`

The first argument `r : α → α → Prop` is the bounding relation on the codomain type `α`; for instance `(· ≤ ·)` gives eventual upper-boundedness and `(· ≥ ·)` gives eventual lower-boundedness. The second argument `f : Filter β` is the filter along which eventual behaviour is measured; common choices are `atTop` (for sequences indexed by a directed type) or `nhds x` (for local behaviour). The third argument `u : β → α` is the function whose values are being tracked; it maps indices (or points of a topological space) to elements of the ordered type `α` where the bound lives.

## Conventions

No junk-value or out-of-domain conventions are declared for this definition: it is a universally quantified `Prop` over all types `α`, `β`, any relation `r`, any filter `f`, and any function `u`, so every input combination is meaningful and yields a well-formed proposition (which may simply be `False` for a given combination).

## Worked examples

- Claim: A constant function `fun _ => a` is always `IsBoundedUnder r l (fun _ => a)` whenever `r` is reflexive, because the constant value bounds itself.

- Claim: If `u : ℕ → ℝ` tends to `+∞` along `atTop` (i.e., `Tendsto u atTop atTop`), then `VTask.IsBoundedUnder (· ≥ ·) atTop u` holds — the sequence is eventually below no fixed upper bound in the downward direction, but *is* eventually bounded below (every value is eventually ≥ some bound).

- Claim: If the range of `u : β → α` is bounded above (i.e., `BddAbove (Set.range u)` holds in a preorder), then `VTask.IsBoundedUnder (· ≤ ·) f u` holds for any filter `f` on `β`, because the global upper bound works as a uniform eventual upper bound.

- Claim: For a finite type `β` with a directed order on `α`, `VTask.IsBoundedUnder (· ≤ ·) f u` holds automatically for any `f` and `u`, since there are only finitely many values.

## Boundaries

- When `f` is the `⊥` filter (the principal filter of the empty set, or the filter generated by `∅`), every proposition about eventual behaviour holds vacuously, so `VTask.IsBoundedUnder r ⊥ u` is always true regardless of `r` and `u`.
- When `f` is the `⊤` filter (the filter requiring all sets), `VTask.IsBoundedUnder r ⊤ u` requires the entire range of `u` to be bounded by some single element under `r`, which is a strong global requirement.
- If the relation `r` is reflexive, then `VTask.IsBoundedUnder r f (fun _ => a)` holds trivially for any constant function, as `a` bounds itself.
- The definition does NOT require `r` to be a preorder or have any structural properties; it works for arbitrary binary relations, though interesting theorems about it typically assume at least a preorder.
- For `r = (· ≤ ·)` and `f = atTop` on `ℕ`, this coincides with the classical notion of a sequence being eventually bounded above.

## Not to be confused with

- `Filter.IsBounded r f`: asserts that the filter `f` itself (not the image of `f` under some function) is bounded with respect to `r`; `VTask.IsBoundedUnder r f u` is exactly `Filter.IsBounded r (map u f)`.
- `BddAbove (Set.range u)`: asserts that the *entire* range of `u` is bounded above globally, which is strictly stronger than eventual boundedness along a proper filter.
- `Filter.Tendsto u f (nhds a)`: asserts convergence of `u` to a specific limit `a`, which implies eventual boundedness but is a much stronger statement.

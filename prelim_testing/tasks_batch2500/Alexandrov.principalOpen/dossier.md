## VTask.principalOpen

### Object

Given an element `x` of a topological space `X` equipped with a preorder whose open sets are exactly the upper sets (an Alexandrov-type topology where opens coincide with upward-closed sets), `VTask.principalOpen x` is the smallest open set containing `x` — namely, the *principal upper set* (or *principal open*) generated by `x`. Its underlying carrier is the set of all elements `y ∈ X` with `x ≤ y`, packaged as an element of `Opens X` (an open subspace together with its openness proof).

### Signature

<!-- PINNED-SIGNATURE:BEGIN -->
VTask.principalOpen : {X : Type v} -> [TopologicalSpace X] -> [Preorder X] -> [Topology.IsUpperSet X] -> (x : X) -> TopologicalSpace.Opens X
<!-- PINNED-SIGNATURE:END -->


The type-class arguments supply the ambient topological space structure, the preorder, and the compatibility condition asserting that open sets are upper sets (so that every upper set is open). The explicit argument `x : X` is the generating element: the returned open set is the upward closure of the singleton `{x}`, i.e., all `y` with `x ≤ y`.

### Conventions

No junk-value or degenerate-input conventions are declared for this definition: it is a total construction defined for every element `x` of any type carrying the required instances, and the result is always a well-formed open set.

### Worked examples

- Claim: For the natural numbers with the Alexandrov upper-set topology, `VTask.principalOpen 3` contains `5` (since `3 ≤ 5`).

- Claim: For the natural numbers with the Alexandrov upper-set topology, `VTask.principalOpen 3` does not contain `2` (since `¬ (3 ≤ 2)`).

- Claim: For a preorder where `a ≤ b`, the carrier of `VTask.principalOpen a` contains the carrier of `VTask.principalOpen b` (i.e., `principalOpen` is antitone: a smaller generating element yields a larger open set).

- Claim: The element `x` itself always belongs to `VTask.principalOpen x`, since `x ≤ x` by reflexivity of the preorder.

### Boundaries

- **Top element**: If `x` is the top element of a bounded order (i.e., `x = ⊤`), then `VTask.principalOpen x` is the singleton `{⊤}` (only the top element satisfies `⊤ ≤ y`).
- **Bottom element**: If `x` is the bottom element (i.e., `x = ⊥`), then `VTask.principalOpen x` is the whole space, since every `y` satisfies `⊥ ≤ y`.
- **Discrete order**: If the preorder is the discrete equality order (`x ≤ y ↔ x = y`), then `VTask.principalOpen x` is exactly the singleton `{x}`.
- **Antichain**: If `x` is incomparable with all other elements (belongs to a complete antichain), then `VTask.principalOpen x = {x}` as well.

### Not to be confused with

- **`TopologicalSpace.Opens.interior`**: The interior of an arbitrary set, which is not necessarily an upper-set principal open and does not require an order structure.
- **Principal filters / `Filter.principal`**: The principal filter generated by a set `{y | x ≤ y}` lives in the filter lattice, not in `Opens X`; `VTask.principalOpen` produces an honest open subspace, not just a filter.
- **`nhds x` (neighborhood filter)**: In this upper-set topology the neighborhood filter of `x` is generated by `VTask.principalOpen x`, but `nhds x` is a filter of sets, not a single open set.
